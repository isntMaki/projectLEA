# doc_register_named_styles

注册/更新 DOC 命名样式（论文模板修复专用）。role 是调用方的中文样式键，例如“章标题”“摘要正文”“三线表”。每个 styles[] 条目必须声明 style_type：paragraph、paragraph_with_character_styles、character 或 table。1) 源样本模式：source_file_id + source_range，工具从样本 range 读取有效格式。style_type=paragraph 时，工具读取 source_range 起点段落属性生成 paragraph 样式，并把 range 内 run_style 最大公共集合写入该段落样式，不自动派生 character 样式。style_type=character 时，只从 source_range 采 run 属性注册字符样式，paragraph_style 必须为空；w:name 用 role（论文流程用「{业务role}字符」避免和段样式重名）。style_type=paragraph_with_character_styles 时，在 paragraph 行为基础上，把不同 run 的非公共 delta 自动派生为 character 样式，并在 registered_styles 中通过 parent_role/source_ranges 返回。style_type=table 时，source_range.begin 须落在表内，end 须落在同一张表（半开区间 [begin,end)，end 可以是表的右开终点）；begin 命中哪张表就抽整张表。工具按表级 tblBorders 与格子 tcBorders 合成视觉边框；底纹看格子直设 w:shd，缺省回落表级 tblPr/shd，整表同一色写 fill（style tcPr/shd），仅首行不同则另写 first_row.fill；不解析源表 named style 的 band。cell_margin 拷表级 tblCellMar（有则写）；v_align 仅在全部格子直设且一致时写；行高仅在每一行都指定且一致时写成整表 row_height，否则只保留 first_row/last_row（未指定的行视为 auto，不会被表头高度带成整表行高）；再读与整表不同的首末行条件边。不收列宽，不支持首/末列、角单元格或横/竖条带（firstCol / lastCol / neCell / nwCell / seCell / swCell / band1Horz / band2Horz / band1Vert / band2Vert）。与显式 table_style 互斥。2) 原始样式克隆模式：style_type=paragraph/character + clone_source_style=true + source_file_id + source_style_name。跨文档复制 source_style 的原始 rPr/pPr，以及 basedOn/link/next 依赖链；paragraph_style/run_style 仅作为显式 overlay。源样式 pPr.numPr（含 basedOn 继承）会解成 numbering_definition / numbering_type，并把 abstractNum 编进目标文档；同批相同 numbering_source_id 共享 numId。overlay 已写 numbering_type/numbering_definition/numbering_lvl/numbering_source_id 时不再自动抽编号。3) 显式段落模式：只支持 paragraph，调用方直接传 paragraph_style + run_style。显式字符模式：style_type=character + run_style，paragraph_style 必须空。编号使用平铺字段 paragraph_style.numbering_type/numbering_lvl；非 preset 的 Word 自定义列表（含 numStyleLink 编号样式）由 source_sample 或 clone_source_style 写入 paragraph_style.numbering_definition，并把真实 abstractNum 编进目标文档。4) 显式表格模式：style_type=table + table_style，注册 OOXML table style；只收可复用外观（边框、单元格边距、默认垂直对齐、整表 fill、默认行高、首末行条件格式），不收列宽，不支持行条带。表格两种模式只能选一种。冲突策略：同名样式复用原 styleId；属性相同但 role 不同时仍各自注册新 styleId /
